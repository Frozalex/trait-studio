Trait Studio is an independent fork of [StykAnimate](https://github.com/filippocalippo/StykAnimate-App), created from commit `def97214c2b491fbce82647f625a73f78416c6d8`.

The original authors’ copyright notices, GPL-3.0-or-later license, third-party notices and Git history are retained. Trait Studio adds its own identity and Workshop tools. It is not affiliated with or endorsed by StykAnimate, Stick Nodes or Pivot Animator. Those names refer to the upstream project or compatible file formats. No proprietary Stick Nodes source code or assets are included.

The original project documentation is retained in `docs/UPSTREAM-README.md` and the existing architecture documents. Some historic documentation describes upstream services and release infrastructure that this fork does not use. See `docs/TRAIT-STUDIO.md` for the fork’s current behavior.
